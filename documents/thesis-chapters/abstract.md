# Abstract

## English Abstract

Programming education at universities worldwide faces a persistent challenge: high failure rates averaging 30--40% in introductory courses, driven by the fundamental mismatch between the individualized, practice-intensive nature of programming skill acquisition and the uniform, resource-constrained reality of large-class instruction. Existing online coding platforms such as LeetCode, HackerRank, and Codeforces offer extensive problem repositories but employ static difficulty classifications and provide no mechanism for personalized learning path adaptation. Meanwhile, academic research on adaptive learning for programming has addressed individual components --- knowledge tracing, difficulty calibration, problem recommendation, or spaced repetition --- in isolation, without integrating them into a unified, closed-loop system.

This thesis presents the design, implementation, and evaluation of an Adaptive Learning Platform for University Programming Courses that addresses this integration gap. The platform is built on a five-layer adaptive engine unified through a knowledge graph of approximately 30 programming concepts connected by prerequisite relationships. Layer 1 employs Bayesian Knowledge Tracing (BKT) to estimate per-concept mastery probabilities for each student. Layer 2 implements a Dynamic K-Value Elo rating system that continuously calibrates problem difficulty relative to individual student ability. Layer 3 uses Hierarchical Multi-Armed Bandits (H-MAB) with Thompson Sampling for intelligent problem selection, respecting both prerequisite constraints from the knowledge graph and Zone of Proximal Development constraints from Elo ratings. Layer 4 applies the Free Spaced Repetition Scheduler (FSRS) --- for the first time in the programming education domain --- to schedule concept reviews and prevent skill decay over time. An optional Layer 5 provides LLM-powered Socratic hints through a Retrieval-Augmented Generation pipeline grounded in the student's knowledge state.

The system operates as a closed loop: each code submission triggers asynchronous updates to all adaptive layers, continuously refining the learner model and influencing subsequent recommendations. The platform is implemented as a full-stack web application comprising a React frontend, a NestJS API backend, a FastAPI-based adaptive engine, a PostgreSQL database, and a Docker-based sandboxed code execution environment.

The system is evaluated through a between-subjects experiment with pre-test and post-test design, comparing the adaptive platform (experimental group) against the same platform with adaptive features disabled (control group), involving 40--60 undergraduate students at Hanoi University over a four-week intervention period with a follow-up retention test at Week 8. Evaluation metrics include Normalized Learning Gain (NLG), BKT and Elo prediction accuracy (AUC-ROC), recommendation acceptance and completion rates, FSRS-based retention outcomes, and usability assessments using the System Usability Scale (SUS) and Technology Acceptance Model (TAM). A within-system ablation study using feature-flag-based layer disabling and interaction log replay provides evidence for each layer's marginal contribution.

This thesis makes four contributions: (1) the first integrated multi-layer adaptive architecture combining BKT, Elo, MAB, and FSRS for programming education; (2) a prerequisite-constrained Hierarchical MAB algorithm for problem selection gated by BKT mastery states; (3) the first application of FSRS to programming skill retention, with a novel rating mapping from code submission outcomes to spaced repetition review ratings; and (4) an open-source, deployable adaptive learning platform designed for the Vietnamese university context.

**Keywords:** adaptive learning, knowledge tracing, multi-armed bandits, spaced repetition, programming education, Elo rating system
